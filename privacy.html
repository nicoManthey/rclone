Datenschutzerklärung

Stand: 20. November 2026

Zweck

Diese Anwendung („rclone Zugang“) ist ein privates, nicht-kommerzielles Projekt von Nico Manthey. Sie dient ausschließlich dazu, dass der Betreiber mit dem Open-Source-Tool rclone auf seine eigenen Google-Konto-Daten (z. B. Google Drive) zugreifen kann.

Welche Daten verarbeitet werden

Über die Google-APIs werden nur die Dateien und Metadaten verarbeitet, auf die der angemeldete Nutzer rclone ausdrücklich Zugriff gewährt. Die Verarbeitung findet ausschließlich lokal auf dem Rechner des Nutzers statt. Zugriffstoken werden nur lokal in der rclone-Konfiguration gespeichert.

Weitergabe

Es werden keine Daten an den Betreiber oder an Dritte übermittelt, gespeichert, verkauft oder für Werbung genutzt. Es gibt keinen Server, der Nutzerdaten empfängt.

Nutzung von Google-Nutzerdaten

Die Nutzung und Übertragung von Informationen, die über Google-APIs empfangen werden, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
